Los mapas hacia las ruinas son como scrolls, una vez llegas, desaparecen. No se pueden copiar ya que al tener tinta o papel cerca, los mismos se ponen en blanco. Se puede usar Dispell Magic para destruirlos. 

Para ver el mapa, debe sostenerse con las dos manos y solo se hace visible para aquel que lo sostiene. Las palabras se escriben mágicamente una vez se lo toca con las dos manos como si aparecieran del aire y se pegaran al papel, y una vez se lo suelta, desaparece todo el texto en magículas que se pierden en el aire.
